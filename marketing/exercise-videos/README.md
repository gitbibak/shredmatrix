# Full Balance exercise videos

Everything lives in **[studio3d/](studio3d/README.md)**: the approved 3D pipeline (engine, 250 exercise definitions, docs, render/encode/upload scripts).
`research/` holds the movement specs (`research/specs/*.json`) and the app exercise name list the pipeline reads.
`package.json` provides the shared dependencies (`three`, `playwright`) used by studio3d (`npm install` here).

Earlier experiments (SDF mannequin, 2D flat, sphere-hull 3D, Blender renders) were removed on 2026-10-04.
