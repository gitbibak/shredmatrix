# App integration plan: exercise videos in Full Balance (agreed 2026-10-04)

## Decisions
- Hosting: **Cloudflare R2** bucket, public via custom domain **media.fullbalance.app** (same Cloudflare account/zone as the app). No egress fees; 10 GB free storage.
- Player: **in-app modal** with a vertical `<video playsinline controls>` (poster shown before load). Close returns to the workout.
- Languages: **TR only for now**. TR UI: video button replaces the YouTube link; YouTube path closed in TR. EN/ES UI keep the YouTube link until their videos exist, then switch with no code change.
- eight_angle_pose: shown as the prep version (cards already say so).

## Delivery files
- Encode from the 1080p masters: 720x1280, 60 fps, H.264 High, CRF 24, `+faststart`, no audio → ~2.6 MB/video (~650 MB for TR, ~2 GB for 3 languages).
- Poster: JPG 720x1280 from the intro frame (t≈1.5 s), ~60 KB.
- Path scheme (versioned for cache busting): `https://media.fullbalance.app/v1/<lang>/<id>.mp4` and `.../v1/<lang>/<id>.jpg`. Long cache headers (`Cache-Control: public, max-age=31536000, immutable`); a new render = new version folder (`v2/`).
- Masters (1080p) stay local in `studio3d/out/<lang>/` as the archive.

## Name → video mapping
- Build `src/data/exerciseVideos.js` (generated by `pipeline/build_video_map.py` from `exercises/_manifest.json`): `{ normalizedAppName: specId }`.
- Covered directly by `app_names`: 298 of 390 app names. Extra normalization: strip prefixes like `Devre — `, `Devre (3 tur) — `, `Süperset: A + B` (first exercise or both), suffixes in parentheses (tempo/RPE/variants) → ~20 more.
- No video (button hidden): rest days, walking/cardio, meditation, flows (`non_demo`), ~70 names.
- Exposed as `getExerciseVideo(name, lang)` → `{ src, poster } | null`; returns null for languages without videos yet (`AVAILABLE_LANGS = ['tr']`).

## App changes (src/components/WorkoutPanel.jsx + new ExerciseVideoModal.jsx)
- In `ExerciseRow`: if `getExerciseVideo(exercise.name, lang)` → render "Videoyu izle" button (play icon) opening the modal; else if lang is TR → no video button; else keep the existing YouTube link.
- Modal: portrait 9:16, max-height 85vh, `preload="none"`, poster, autoplay on open (muted not needed — videos have no audio), `playsInline`, close on backdrop/Esc, focus trap, i18n strings (tr/en/es).
- Analytics: optional `exercise_video_play` event if the app's analytics helper exists.
- Tests: mapping unit test (known names → ids, rest/cardio → null, EN/ES → null for now); component test for the button/modal.

## Steps (each confirmed with the user)
1. Encode 250 TR delivery videos + posters (local, ~30 min, no AI usage).
2. Create R2 bucket `fullbalance-media` + custom domain `media.fullbalance.app` (Cloudflare dashboard or `wrangler r2 bucket create`; needs the user's Cloudflare login) — **user approval**.
3. Upload `v1/tr/*` (wrangler / rclone), verify a few URLs, CORS for fullbalance.app.
4. App code + tests (local), preview with `npm run dev`.
5. Deploy (wrangler deploy) — **user approval**.
6. Later: EN/ES masters → encode → upload `v1/en`, `v1/es` → add to `AVAILABLE_LANGS`.
