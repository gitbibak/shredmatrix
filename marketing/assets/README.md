# Sosyal Kampanya Gorselleri

Bu klasordeki gorseller metinsiz premium zeminlerdir. Metinleri `marketing/creative-briefs.md` dosyasindaki exact haliyle uzerine ekle.

## Dosyalar

- `full-balance-6-modules-social.png`
  - Kullanim: Ana tanitim, "6 modul tek uygulama", ucretsiz app mesaji.
  - Uygun platformlar: TikTok/Reels kapak, Pinterest ana pin, story.

- `full-balance-muscle-social.png`
  - Kullanim: Kas gelisimi, protein, antrenman, ilerleme raporu.
  - Uygun platformlar: TikTok/Reels kapak, Pinterest kas gelisimi panosu.

- `full-balance-wellness-social.png`
  - Kullanim: Yoga, pilates, reformer, meditasyon ve uyku.
  - Uygun platformlar: TikTok/Reels kapak, Pinterest wellness panolari.
